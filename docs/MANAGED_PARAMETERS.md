# 受管参数的范围与生效方式

参数页承载有明确消费者的运行期偏好。新增键之前应确定作用域、消费者、默认值、校验和生效时机；业务专属键放项目作用域，不自动成为平台默认。

| 键 | 用途与作用域 | 约束 / 生效 |
| --- | --- | --- |
| `app.admin.brand` | 生成的业务后台侧栏品牌，全局默认可按项目覆盖 | 新生成前端读取项目生效配置，约 5 分钟刷新；已交付项目需自行接入 |
| `app.admin.label` | 生成的业务后台侧栏名称，全局默认可按项目覆盖 | 同上；不会改写平台侧名称 |
| `common.table.page_size` | 生成的业务 CRUD 列表默认每页条数，全局默认可按项目覆盖 | 整数 5–200，非法时用 20；约 5 分钟刷新，用户仍可调整当前列表每页数量 |
| `platform.notification.poll_seconds` | 平台消息铃铛刷新间隔，仅全局 | 非敏感整数 15–600 秒，默认 60；在线时约 60 秒刷新配置 |
| `platform.factory.poll_seconds` | 平台项目工厂运行中任务刷新间隔，仅全局 | 非敏感整数 2–60 秒，默认 3；在线时约 60 秒刷新配置 |
| `platform.home.poll_seconds` | 平台工作台运行中任务刷新间隔，仅全局 | 非敏感整数 2–60 秒，默认 5；在线时约 60 秒刷新配置 |

平台界面只通过 `/api/current/ui-preferences` 读取后三个固定键及有界整数，必须登录；其他配置、项目覆盖、敏感值不通过此端点外发。禁用、删除、缺失、格式错误或越界时使用默认值。用户改动由原有权限控制及审计约束。

项目配置只经现有项目授权读取接口提供，项目值覆盖全局值；令牌变化时丢弃项目配置缓存并重新读取。项目工厂只影响后续生成的项目，既有业务仓库不能自动修改。不同项目应根据自身需要添加和消费业务参数。

模型连接参数、存储绑定、定时任务和语言资源保留原有专门管理入口；凭证、安全边界、数据库与网络地址、协议大小限制及基础设施参数留在部署和安全配置中，避免多处配置覆盖。测试、性能或业务需求明确后可评估更多参数，不能仅插入键而不实现消费和约束。

## 用 CLI 管理业务项目参数

先在业务后端仓的 `kaiwu/configs.yml` 声明项目配置，再从已更新的入口仓执行：

```bash
./kaiwu project sync <业务后端仓路径>           # 先查看完整计划，不写入
./kaiwu project sync <业务后端仓路径> --apply   # 已获授权且计划符合任务范围时执行
```

先核对 CLI 实际连接的环境、登录身份、项目编码和整个计划：同步会同时处理该仓存在的菜单、字典、参数、定时任务和国际化清单，而不仅是配置。角色和授权默认不导入；需要时使用 `--with-access` 并审核其计划。已有参数的运行值由运营维护，同步不覆盖；同步后应查询目标项目的实际配置并验证消费者生效。

`project sync` 只作用于业务项目，不能创建平台全局默认或修改 `system` 项目。本页三个 `platform.*` 是平台内置默认值，由 V116 随版本迁移安装；三个已有的全局业务默认值由平台种子提供。业务项目需要不同值时才在对应项目范围维护。CLI 无法替代代码中的消费者、范围校验或平台全局种子的 Flyway 迁移。

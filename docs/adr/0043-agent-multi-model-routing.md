# ADR 0043：AI 助手按用途配置模型

- 状态：Accepted（按 PLAN / ANSWER 配置模型已合入，随 0.2.0 发布）
- 日期：2026-10-31

## 决策

复用既有供应商配置表保存多个 OpenAI 兼容模型配置，保留 id=1 的历史默认配置。新增用途绑定，分别指定 PLAN（识别和规划）与 ANSWER（回答）；空绑定沿用 id=1，不将已有密钥明文迁移或重新加密。空库没有默认配置时由管理员显式选择模型。

配置与绑定继续使用现有 AI 管理权限；密钥加密保存，接口只返回是否已配置。改变服务地址时必须显式更换或清除已有密钥。保存配置清除之前的连接测试结果并递增配置修订号；测试结果只写回相同修订号，配置已变更时提示重新测试。

任务开始固定两阶段模型的标识、地址、模型名及调用参数，不保存密钥；每次调用前重新读取当前凭据并检查用途绑定和目标，目标改变或原有密钥清除时停止调用。同目标密钥轮换使用新密钥。禁止静默切换供应商；既有出站网络策略、能力校验、权限及操作确认仍然生效。阶段日志分别记录调用模型，原有汇总事件的单一模型字段仍记录规划模型。

V117 同步 MySQL、达梦与 Helm 迁移。旧单模型 API 保留，以支持已有调用方；前后端须配套发布。当前实现未提供模型停用、删除或自动回退；也不承诺模型调用一定更快。配置生效后应使用脱敏评测集验证规划准确率、耗时与费用。

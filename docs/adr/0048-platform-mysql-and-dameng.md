# ADR 0048：首次部署选择 MySQL 或达梦

- 状态：Accepted
- 日期：2026-10-29
- 编号说明：原编号 0041，与「项目内统一文件记录」重号；2026-11-12 改为 0048，正文未变。
- 范围：平台控制面部署、持久化和初始化。

平台默认栈原为 MySQL，新增达梦 DM8 作为首次安装选项。
数据库选择属于部署配置，在拉取运行仓库及创建平台运行配置之前确认并保存；
薄入口获取 System 后委托 System 向导，不复制数据库事实源。
已有安装保持 MySQL 语义，不允许通过环境变量隐式迁移存量数据。

MySQL 与达梦使用各自 JDBC 协议和 Flyway 迁移目录。
MySQL 的已发布迁移保持不可变。达梦 V99 基线取自一次性 MySQL 执行到 V99 后的
38 张表和 1,657 条种子；V100 起在两种数据库中维护对应版本。
达梦基线保留主外键和唯一约束，字符列使用 CHAR 长度语义，自增日志列使用 IDENTITY。
MySQL 自动生成的同名外键索引在达梦加 `ix_dm_` 前缀，避免索引与约束重名。

数据层继续只使用 MyBatis-Plus。JDBC 元数据决定分页方言和 MyBatis databaseId；
达梦差异 SQL 使用 `databaseId="dm"`，MySQL 语句保持原样。
冲突更新使用 MERGE，使用相关查询先按唯一键定位现有主键，允许更新原唯一键字段。
授权谓词、状态机守卫、乐观锁和 JSON 单语言更新语义必须保持一致并通过真库测试。

达梦迁移运行在独立工具模块和容器，应用不在启动时隐式执行迁移。
固定使用 Flyway 12.11.0 与社区 DM8 插件 12.11.0。插件原实现误把 Schema 自身的 SCH
记录计入非空对象；工具模块以同名 Schema 适配类修正该判断，并禁止创建、删除、清空用户。
镜像 classpath 必须把工具 classes 放在依赖 JAR 前，此装配需在真实达梦测试中验证。
工具只允许受管独立 Schema，禁止 clean、repair 和自动 baseline。

达梦实例和许可由部署方提供；平台不分发数据库服务端。
项目工厂生成业务库和 DDL 导入仍遵守现有 MySQL 契约，不跟随平台数据库自动改变。
详细操作、测试要求与已有限制见 `docs/DATABASES.md`。
